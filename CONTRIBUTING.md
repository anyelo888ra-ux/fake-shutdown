# Contribuir

¡Gracias por ayudar a mejorar Fake Shutdown Simulator!

## Antes de abrir un issue
- Busca si ya existe un reporte parecido.
- Usa el formulario de errores para fallos.
- Usa el formulario de sugerencias para nuevas funciones.
- Incluye navegador, sistema y pasos para reproducir el problema cuando sea posible.

## Reglas del proyecto
- Es una simulación visual que funciona dentro del navegador.
- Nunca debe apagar, reiniciar, bloquear ni modificar el dispositivo real.
- Debe existir siempre una salida visible mediante ESC o el botón Salir.
- No se deben ocultar avisos que expliquen que la experiencia es ficticia.
- Prioriza HTML, CSS y JavaScript sin dependencias pesadas para mantener compatibilidad con equipos modestos.
- Respeta las marcas y atribuciones de terceros; los elementos NOVA son una marca conceptual del proyecto.

## Cambios
Describe el objetivo del cambio, las pruebas realizadas y añade capturas si ayudan a revisarlo.
